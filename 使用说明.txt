========================================
        AI 内容工厂 —— 使用说明
========================================

【这是什么】
这是一款 AI 内容生成工具。
每天点一下按钮，自动帮你生成 5 个平台的图文文案：
抖音、小红书、公众号、B站、微博。

你不用自己想选题、不用自己写文案。
1 分钟就能出 5 篇稿子，根据平台不同风格和深度也不同，可以自己挑选
目前指定关乎ai内容生成，可自行更改prompt以及搜索网站来达到不同领域的内容生产

----------------------------------------
【第一步：获取 API Key】
----------------------------------------
本软件需要调用 DeepSeek 的 AI 服务，
你需要先注册一个 DeepSeek 账号，拿到一把"钥匙"（API Key）。

操作步骤：
1. 打开浏览器，访问：https://platform.deepseek.com
2. 用手机号注册并登录
3. 登录后，点击左侧菜单里的「API Keys」
4. 点击「创建 API Key」，复制那一长串字符（以 sk- 开头）
5. 把它保存好，下一步要用

⚠️ 注意：
- DeepSeek 是收费服务，但非常便宜。
  每天生成 5 篇文案，成本大约几分钱。
- 新用户通常有免费额度，可以先试用。
- API Key 是你账号的密码，不要泄露给任何人。


----------------------------------------
【第二步：首次打开软件】
----------------------------------------
1. 双击 "AI内容工厂.exe"
2. 首次打开会弹出一个窗口，要求输入 API Key
3. 把第一步复制的那串字符，粘贴进输入框
4. 点击「验证并保存」
5. 软件会自动验证 Key 是否有效：
   - 验证通过 → 进入主界面
   - 验证失败 → 按提示修改后重试

之后每次打开软件，都不会再让你输入 Key。


----------------------------------------
【第三步：生成文案】
----------------------------------------
1. 在软件主界面，点击「一键生成今日内容」
2. 界面会显示生成进度
3. 大约 1-2 分钟后，5 个平台的文案全部生成完毕
4. 文案会自动保存到软件目录下的 output 文件夹里


----------------------------------------
【第四步：找到并复制文案】
----------------------------------------
文案的存放路径是：
   output / 日期 / 平台 / 时间戳 / 标题.md

举个例子，你今天生成的抖音文案，可能在：
   output / 2026-09-27 / dy / 20-15-33 / AI圈今天杀疯了.md

每个 .md 文件里包含两部分：
   【标题】—— 文章的标题
   【正文】—— 文章内容

打开文件，复制里面的内容，
粘贴到对应平台的编辑器里，发布即可。


----------------------------------------
【第五步：发布】
----------------------------------------
1. 打开对应平台的 App（抖音 / 小红书 / 公众号 / B站 / 微博）
2. 粘贴标题和正文
3. 配上你自己的封面图
4. 发布


----------------------------------------
【常见问题】
----------------------------------------

Q1：软件打开后没反应，一直显示"正在抓取热点"？
A：可能是网络问题。请检查网络连接后重试。
   如果一直失败，可能是新闻源被限制，请稍后重试。

Q2：生成出来的文案不符合我的风格？
A：本软件的文案风格是预设的，暂时不支持自定义。
   如需定制专属风格，请联系作者（见下方联系方式）。

Q3：我换了电脑，软件还能用吗？
A：可以。API Key 是绑定你的 DeepSeek 账号的，
   在新电脑上重新输入一次即可。
